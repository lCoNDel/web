Capacidades de la Plataforma

Conocimiento (RAG)

La plataforma convierte años de conocimiento interno (manuales Mercury, boletines de fábrica, procedimientos de taller, etc) en un activo digital consultable. El empleado pregunta en lenguaje natural; el sistema localiza la respuesta exacta con referencia al documento fuente.

  • Manuales técnicos, boletines y fichas de producto
  • Respuestas precisas con cita al documento original
  • Escalable: añadir nueva documentación es inmediato y se pueden usar fuentes externas, Sharepoint, Outlook, etc.

Agentes a Medida

Cada departamento o incluso cada persona puede tener su propio agente IA personalizado. Un Agente Contable puede tener acceso a datos sensibles como ventas, compras, tener sus propias herramientas como calculadora científica, acceso al ERP etc, mientras que uno de Marketing solo tendría acceso a documentación de su área y herramientas como generación de imagenes desde la plataforma.

  • Identidad, instrucciones y distintas bases de conocimiento por agente
  • Múltiples agentes activos simultáneamente
  • Se crean, ajustan y retiran sin interrumpir el servicio

Control Total de Accesos

La plataforma permite un acceso granular completo: que agentes puede usar X empleado o Departamento, a que herramientas puede acceder y qué bases de conocimiento puede consultar. Lo que no está autorizado sencillamente no existe para ese usuario.

  • Gestión de permisos por usuario o grupo
  • Acceso granular: herramienta A sí, herramienta B no
  • Trazabilidad: registro de uso, consumo de tokens, costes, etc.

Acceso Móvil - Telegram

Los empleados en campo pueden consultar el mismo asistente directamente desde su móvil por Telegram, sin abrir el navegador. Análisis de imágenes, documentos y respuestas en tiempo real, estén donde estén.

  • Sin instalar nada: solo Telegram
  • El mismo agente, con la misma base de conocimiento
  • Acceso restringido: solo usuarios autorizados

Generación de Documentos

El agente redacta un informe, una oferta o una ficha técnica y lo entrega como archivo listo para descargar, Word, Excel, CSV, etc, directamente desde el chat. También permite previsualizar contenido html, para presentaciones, esquemas, etc.

  • Word, Excel, CSV, JSON, Markdown
  • El agente redacta; la plataforma formatea y empaqueta
  • Descarga directa desde el propio chat

Escalabilidad Total

La plataforma puede conectarse a SharePoint, al ERP Libra, a agencias de transporte o a modelos externos como ChatGPT o Claude cuando la tarea lo requiera. Diseñada para crecer cuando queramos.

  • SharePoint Online, Dynamics, ERP Libra
  • APIs externas: agencias de envío, proveedores, webs
  • Modelos premium externos (ChatGPT, Claude) bajo demanda
